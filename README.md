## Featured Projects

### [Vibra](https://github.com/UNIZAR-30226-2025-09/frontend_mobile) — Music Streaming & Social App
A music streaming application that blends listening with social networking: users can play songs, share and recommend playlists with friends, and chat in real time. This repository contains the **Android (Kotlin) client**, built as part of the Software Project course at the University of Zaragoza.
`Kotlin` `Android` `Docker`

### [DAI-MOM](https://github.com/gaxur/DAI-MOM) — AI-Filtered Message-Oriented Middleware
A distributed Message-Oriented Middleware (MOM) implemented with **Java RMI**, featuring a custom broker, producers/consumers, durable and non-durable queues, and round-robin fair dispatch. What sets it apart is a pipeline of pluggable **AI agents** that automatically filter messages (spam, content, length, and channel rules) before they reach consumers.
`Java` `RMI` `Distributed Systems` `Multi-Agent Filtering`

### RoomSense — IoT Library Room Monitoring System
An IoT-based system that monitors and optimizes library room conditions (temperature, humidity, occupancy) in real time and gives AI-powered room recommendations, developed for the IoT course at the University of Modena and Reggio Emilia.
- [Mobile app](https://github.com/MDN-IA/frontend-mobile) — Kotlin/Android client with a real-time dashboard
- [Backend](https://github.com/MDN-IA/backend) — Node.js/Express API, PostgreSQL, Docker, and an ML recommendation model, connected to ESP32 sensors
`Kotlin` `Node.js` `Express` `Docker` `Machine Learning` `IoT`

### [MDN-Distributed-Edge](https://github.com/gaxur/MDN-Distributed-Edge) — Resiliency Patterns for Microservices
A hands-on demonstration of client-server resilience patterns between two Spring Boot microservices, using **Resilience4j**: Retry, Circuit Breaker, Bulkhead, Timeout, and Fallback, complete with test scripts that reproduce each failure scenario and Docker Compose orchestration.
`Java 21` `Spring Boot` `Resilience4j` `Docker Compose`

### [MDN-C-CS](https://github.com/gaxur/MDN-C-CS) — Hallucination Evaluation in Vision-Language Models
A research-oriented project studying **hallucination in Vision-Language Models** (object, attribute, relation, and counting errors). Includes a synthetic benchmark generator, evaluation pipelines for models such as LLaVA-v1.5 and Qwen3-VL, a prompt-engineering mitigation study, and SLURM scripts for GPU-cluster execution.
`Python` `PyTorch` `VLMs` `HPC/SLURM` `Jupyter`

### [Camping App (Verification & Validation)](https://github.com/Grupo15Unizar/unizar-vv-15_camping)
An Android application developed as a team project for the Software Verification & Validation course, focused on applying testing and quality-assurance practices throughout the development lifecycle.
`Kotlin` `Android` `Software Testing`

### [sisinf2](https://github.com/gaxur/sisinf2) — Information Systems Infrastructure
A Docker-based deployment project for the Information Systems course, covering containerized services, environment setup, and automated backup scripting.
`Docker` `Docker Compose` `Shell Scripting`
