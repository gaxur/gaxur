### [DAI-MOM](https://github.com/gaxur/DAI-MOM) — AI-Filtered Message-Oriented Middleware
A distributed Message-Oriented Middleware (MOM) implemented with Java RMI, featuring a custom broker, producers/consumers, durable and non-durable queues, and round-robin fair dispatch. What sets it apart is a pipeline of pluggable AI agents that automatically filter messages (spam, content, length, and channel rules) before they reach consumers.
`Java` `RMI` `Distributed Systems` `Multi-Agent Filtering`

### [MDN-Distributed-Edge](https://github.com/gaxur/MDN-Distributed-Edge) — Resilience Patterns for Microservices
A two-service Spring Boot system (`order-service` and `product-service`) that implements and validates the core Resilience4j patterns — Retry with exponential backoff, Circuit Breaker, Bulkhead, Time Limiter, and Fallback — under simulated latency and failure conditions. Includes automated shell scripts that trigger and verify each failure mode (e.g. circuit-breaker state transitions, bulkhead rejection under concurrent load), plus Docker Compose orchestration for local reproduction.
`Java 21` `Spring Boot 3` `Resilience4j` `Docker Compose`

### [MDN-C-CS](https://github.com/gaxur/MDN-C-CS) — Hallucination Evaluation in Vision-Language Models
A research project measuring hallucination in Vision-Language Models — cases where a model describes visual content not actually present in the image. Implements a synthetic, self-consistent benchmark with object/attribute/relation/counting trap questions, POPE-style evaluation metrics, and a prompt-engineering mitigation study (baseline vs. strict prompting) across models including LLaVA-v1.5 and Qwen3-VL, with SLURM scripts for GPU-cluster execution.
`Python` `PyTorch` `Vision-Language Models` `HPC/SLURM` `Jupyter`
